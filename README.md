# Automated Stock Checker

Type a model name and see its availability, stock and price, read from an Excel/CSV master file.

- Open `stock-checker/index.html` in a browser. There's no install or server.
- Click **Load spreadsheet** and pick your master file. Every sheet is read, and the columns and currency are detected automatically.
- Your data is remembered in that browser until you load a new file.

Try it with `stock-checker/sample-stock.csv`.

See [stock-checker/HANDOVER.md](stock-checker/HANDOVER.md) for how the code works and what's next (reading the distributor's file from the cloud automatically).
